# Mathematical symbols

The names refer to the local polynomial rings of the indicated calculations.

| Calculation | Sage names | Manuscript meaning |
|---|---|---|
| Frame system | `a`, `b` | Ratios of the principal values of \(B\) |
| Frame system | `p11`, ..., `p33` | \(p_{ij}=e_j\cdot\operatorname{curl}e_i\), in row order |
| Frame system | `t0`, ..., `t5` | \(\tau_0,\ldots,\tau_5\) |
| Frame system | `u0`, `u1` | \(u_0,u_1\) |
| Low rank cylindrical calculation | `rho` | Source cylindrical radius \(r\) |
| State arrays | indices `0,1,2` | Principal labels \(1,2,3\) |
